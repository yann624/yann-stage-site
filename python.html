2) Projet : générateur de mot de passe simple

Objectif :

  • Demander une longueur.
  • Refuser si la longueur est < 8.
  • Générer un mot de passe avec lettres et chiffres.
import random
import string  # pour letters + digits

def generer_mot_de_passe(longueur):
    if longueur < 8:
        print("Erreur : la longueur doit être au moins 8.")
        return None

    caracteres = string.ascii_letters + string.digits
    mot_de_passe = ""

    for i in range(longueur):
        mot_de_passe += random.choice(caracteres)

    return mot_de_passe


print("=== Générateur de mot de passe ===")
longueur = int(input("Longueur du mot de passe : "))

mdp = generer_mot_de_passe(longueur)

if mdp is not None:
    print("Mot de passe généré :", mdp)

Idées d’amélioration pour le stagiaire :

  • ajouter des caractères spéciaux (!@#$%…)
  • limiter la longueur (ex : max 50)
  • proposer de regénérer un mot de passe

🧩 Jour 5 – Projet : Chiffrement César en Python

On réutilise en Python le projet de cryptage César vu dans la partie cybersécurité / cryptage.

Créer un fichier cesar.py :

def chiffrer_cesar(texte, cle):
    resultat = ""
    for char in texte:
        if char.isalpha():
            base = ord('A') if char.isupper() else ord('a')
            resultat += chr((ord(char) - base + cle) % 26 + base)
        else:
            resultat += char
    return resultat


def dechiffrer_cesar(texte, cle):
    return chiffrer_cesar(texte, -cle)


print("=== Chiffrement César ===")
mode = input("Tape C pour chiffrer ou D pour déchiffrer : ").upper()
message = input("Message : ")
cle = int(input("Clé (0 à 25) : "))

if mode == "C":
    print("Message chiffré :", chiffrer_cesar(message, cle))
elif mode == "D":
    print("Message déchiffré :", dechiffrer_cesar(message, cle))
else:
    print("Mode inconnu.")

Exemples de tests :

  • Message : Bonjour, clé : 3
  • Message : HELLO WORLD, clé : 5
