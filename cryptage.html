🔐 Introduction au cryptage César

Le chiffrement César est une méthode de cryptage très simple : on décale les lettres de l’alphabet selon une clé.

Exemple : clé = 3

  • A → D
  • B → E
  • C → F
  • X → A
  • Y → B
  • Z → C

Pour déchiffrer, on applique le décalage inverse (on enlève la clé).

🐍 Code Python du chiffrement César

def chiffrer_cesar(texte, cle):
    resultat = ""
    for char in texte:
        if char.isalpha():
            base = ord('A') if char.isupper() else ord('a')
            resultat += chr((ord(char) - base + cle) % 26 + base)
        else:
            resultat += char
    return resultat


def dechiffrer_cesar(texte, cle):
    return chiffrer_cesar(texte, -cle)


print("=== Chiffrement César ===")
message = input("Message : ")
cle = int(input("Clé : "))

print("Chiffré :", chiffrer_cesar(message, cle))
print("Déchiffré :", dechiffrer_cesar(chiffrer_cesar(message, cle), cle))
