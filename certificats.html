🔐 Qu’est-ce qu’un certificat numérique ?

Un certificat numérique est une sorte de carte d’identité pour un site web. Il permet de vérifier que le site est le bon et que la connexion est sécurisée.

Il sert à :

  • ✔ confirmer l’identité du site
  • ✔ protéger les données échangées grâce au chiffrement
  • ✔ afficher le cadenas 🔒 dans la barre d’adresse

🏫 Exemple simple pour un élève de 3ᵉ

Imagine que tu veux parler à ton professeur : pour être sûr que c’est bien lui, il te montre sa **carte d’identité officielle**.

Sur Internet, un certificat joue la même fonction : il prouve que le site est authentique, pas une copie.

🌐 Où voit-on les certificats ?

Quand tu visites un site sécurisé, tu vois un cadenas dans la barre d’adresse :

  • 🔒 https://google.com
  • 🔒 https://microsoft.com

En cliquant dessus, ton navigateur affiche le certificat du site.

🔒 À quoi sert un certificat ?

1️⃣ Vérifier l’identité du site

Tu sais que tu es sur le vrai site, pas un site pirate.

2️⃣ Chiffrer les données

Grâce à HTTPS, les informations envoyées sont protégées.

3️⃣ Éviter les attaques (phishing, faux sites…)

Un pirate ne peut pas facilement se faire passer pour un vrai site.

🧪 Petite expérience pour ton stagiaire

✔ Aller sur https://google.com

✔ Cliquer sur le cadenas → “Afficher le certificat”

Il pourra voir :

  • 🔸 le nom du site
  • 🔸 la date d’expiration
  • 🔸 l’autorité qui l’a signé
  • 🔸 le type de chiffrement utilisé

Ensuite tester un site sans HTTPS :

⚠ http://example.com → pas de cadenas

🛡 Comment ça fonctionne (version simple)

  1. 1. Le site montre son certificat.
  2. 2. Le navigateur vérifie qu’il est signé par une autorité de confiance.
  3. 3. Si tout est bon → connexion chiffrée.
  4. 4. Le cadenas s’affiche.

Tout cela se fait en **moins d’une seconde**.

🏢 Exemples d’autorités de confiance

  • DigiCert
  • GlobalSign
  • Let’s Encrypt
  • Sectigo

Ce sont des “mairies du web” qui signent les certificats.
