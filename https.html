🔐 Qu’est-ce que HTTPS ?

HTTPS signifie HyperText Transfer Protocol Secure. C’est la version sécurisée du protocole HTTP utilisé pour afficher des pages web.

Avec HTTPS, les échanges entre ton ordinateur et un site web sont :

  • ✔ chiffrés (personne ne peut lire ce que tu envoies)
  • ✔ authentifiés (tu es sur le vrai site)
  • ✔ protégés contre les pirates

🏫 Explication simple (niveau collège)

Imagine que tu écris un message sur une carte postale.

➤ Tout le monde peut le lire → c’est HTTP.


Maintenant, tu mets ton message dans une enveloppe fermée.

➤ Personne ne voit ce qu’il y a dedans → c’est HTTPS.

🔍 Comment reconnaître un site HTTPS ?

  • 🔒 Il y a un cadenas dans la barre d’adresse
  • 🌐 L’adresse commence par https://
  • 🛡 Le navigateur affiche “Connexion sécurisée”

Exemples :

  • https://google.com
  • https://github.com
  • https://amazon.fr

Exemple non sécurisé :

  • http://example.com

🛡 À quoi sert HTTPS ?

1️⃣ Chiffrer la connexion

Les informations envoyées (mot de passe, messages, paiements…) sont protégées.

2️⃣ Vérifier l’identité du site

Grâce au certificat SSL, ton navigateur sait que c’est le vrai site, pas un faux.

3️⃣ Empêcher les attaques

HTTPS empêche les pirates d’espionner, de modifier les pages ou d’injecter un virus.

🧪 Petite expérience pour ton stagiaire

1. Aller sur https://google.com

2. Cliquer sur le cadenas → “Connexion sécurisée”

3. Voir les détails du certificat


Ensuite :

⚠ Aller sur http://example.com → pas de cadenas

🧠 Comment HTTPS fonctionne (explication simple)

  1. 1. Le site envoie son certificat.
  2. 2. Le navigateur vérifie qu’il est vrai.
  3. 3. Ils créent ensemble une clé secrète (chiffrement).
  4. 4. Toute la connexion est chiffrée.

Ce processus se fait automatiquement en moins d’une seconde.
